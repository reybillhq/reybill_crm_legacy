# Upstream notices omitted from published packages

These original texts accompany bundled packages whose npm releases omit license
files. The build uses each notice only for the exact package version in its
filename and fails if a bundled package has no installed or supplied notice.

- `headlessui-vue-1.7.23-LICENSE.txt`: original MIT license from
  https://github.com/tailwindlabs/headlessui/blob/%40headlessui%2Fvue%40v1.7.23/LICENSE
- `leaflet-draw-1.0.4-LICENSE.txt`: original MIT license from
  https://github.com/Leaflet/Leaflet.draw/blob/v1.0.4/MIT-LICENSE.md

Original copyright and permission text is reproduced without changes.
